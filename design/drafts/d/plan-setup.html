2. 用户中心：三把厂商 Key（不是 OpenRouter Key）

右上角 Account。点进去填显示名、邮箱，以及三档各一把原生 key：复杂 / 简单 / 视觉。首页右栏只选模型，不放密码框。

模型下拉里的 ID 仍用 OpenRouter slug（方便对照现网目录），落地时按所选厂商走各自 base_url：DeepSeek / OpenAI / Anthropic / 智谱 / DashScope / Moonshot。不要让客户贴 sk-or-v1-…。

位置现在草稿约定
本机开发config.local.yaml可继续用环境变量；用户中心可空
客户浏览器没有入口Account 面板三把 password，随这次 run 进内存
容器 / 云三档环境变量只作平台兜底；客户 key 优先，不写进镜像

Key 用 type=password，不进 journal / checkpoints.log / 前端 localStorage。占位符随右栏所选厂商变（DeepSeek sk-…，Claude sk-ant-…）。香港盘上的 PDF 产物仍不外传。

点 Start 而三把 key 未齐：中间红条，并自动打开 Account。

4. 没识别到文件

隐藏的 input[type=file] 加上 required 往往不会弹出浏览器原生提示。草稿约定：点 Start 时若 review 没有文件名（取消选择、空提交、非 PDF），阻止跳转，中间栏出现红条，并描红 Review 行。

文案（产品英、方案说明用中）：No review PDF detected. Choose a published systematic review (.pdf), then Start run. 可选源 PDF 仍可不传。

与现网 a review PDF is required（400）对齐，只是提前在客户端说清「系统没拿到文件」。
