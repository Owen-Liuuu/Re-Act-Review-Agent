# Local-only source PDFs

Place source papers here for source-side extraction. PDFs in this directory are
ignored by Git unless an individual file is explicitly whitelisted.

Phase 6A expects:

| file | DOI | redistribution | SHA-256 |
|---|---|---|---|
| `larkin_2015.pdf` | `10.1056/NEJMoa1504030` | local only | `23892FC13522A3D900BADD0C60B9A55299AD1385BE051A91EC506A825383CA28` |

Do not replace a source PDF silently. A different edition or manuscript must be
recorded as a new benchmark version with a new hash.
